# Fighting Styles

Made in Heaven, Silver Instinct and Santoryu in one Forge 1.20.1 mod (needs Player Animator). Press **N** to choose a
style; only the chosen style's keys, HUD and moves are live, so the three kits share keys without clashing.

- **Made in Heaven**: Q summons the Stand; LMB punches; E R T Y G Z X C V H are the Stand's moves. Using the Stand DISC
  also takes up the style.
- **Silver Instinct**: G awakens (Omen, then Zenith; sneak+G reverts). Awakened, double-jump to **fly**, faster in Zenith,
  with a light trail and a flying pose; no fall damage while awakened. LMB strikes, E R T Y Z X C V H are techniques.
- **Santoryu**: choosing it hands you the three katana; hold one, Z / X pick a technique, R cuts.

Built by GitHub Actions on this branch; the jar and in-game screenshots land on `styles-build`.
