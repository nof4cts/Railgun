# Aegis Command (Forge 1.20.1)

A cinematic tactical laptop for Minecraft. One military terminal hosts four tabs:

| Tab | What it does |
| --- | --- |
| **AIRSTRIKE COMMAND** | Live tactical map scanned from the real terrain around the laptop, radar sweep with live contacts, click-to-designate target, three fictional aircraft, approach vector, hold-to-execute, live event feed, animated debrief. |
| **ARSENAL** | Armory scan intro, three weapons with 3D previews, a full inspection bay (drag to rotate, scroll to zoom, close-up views), animation previews, finish + energy colour customisation, equip / unequip / switch. |
| **MISSION HISTORY** | Lifetime stats, scrolling mission log, per-mission detail with impact pattern and chart, re-target and purge. |
| **SYSTEM** | Volume, mute, interface sounds, accent colour, scanlines, noise, fullscreen terminal, boot sequence, cinematic camera, letterbox, subtitles, screen shake. |

Executing a strike plays four cutscenes: alert state on the laptop (A), aircraft bursting from cloud with a flyby and chase cam (B), wide ground shot with release, impacts, shockwave, smoke and camera slow-push (C), and an orbit of the smoke column before fading back to the laptop debrief (D). ESC skips.

All content is fictional and game-oriented. Explosions do not break blocks unless `destroyBlocks` is enabled in `config/aegiscommand-common.toml`.

## Getting started in game
- Craft the **Aegis Tactical Laptop** (glass panes / redstone + compass + redstone / iron ingots) or take it from the *Aegis Command* creative tab.
- Right-click it to open the terminal. Keys `1`–`4` switch tabs.
- Weapons: PHANTOM-9 is unlocked from the start, SPECTRE-7 after 1 mission, TITAN-X after 3 (always unlocked in creative).
- In game: right-click fires (hold for SPECTRE-7, hold and release to charge TITAN-X), `R` reload, `G` inspect, `V` cycle Aegis weapons.

## Building
The jar is built by GitHub Actions on every push (`.github/workflows/build.yml`). Download it from the run's **Artifacts** section.
Locally: JDK 17 + Gradle 8.1.1, then `gradle build` — the jar lands in `build/libs/`.

Textures and models are generated by `tools/generate-assets.ps1` (procedural, no third-party assets). Sounds are layered compositions of vanilla sound events.
